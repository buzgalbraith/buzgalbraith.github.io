**Authors:** Woodward Galbraith, Benjamin M. Gyori
**Presented at:** ISMB 2026 BOKR (talk, abstract); SWAT4HCLS 2026, SBHD 2026, and the Karger Medal Ceremony 2026 (posters)

DGLink is an automated framework for extracting annotations from the metadata and experimental data stored in biomedical data portals, and assembling that information into knowledge graphs.

* Developed an automated framework for extracting annotations from metadata and experimental data stored in biomedical data portals.
* Applied the system to create knowledge graphs across diverse data portals, including the NCI Genomics Data Commons (GDC), the NCI General Data Commons (GC), and the Sage NF Data Portal.
* Implemented a modular schema-matching framework for harmonizing and annotating arbitrary experimental datasets.
* Built several proof-of-concept applications, including an agentic Model Context Protocol (MCP) interface, integration with a literature-derived knowledge graph for pathway discovery, and integration with genomic indexation tools.
