A general-purpose load-balancing strategy that leverages sketching data structures to efficiently distribute genomic sequences over distributed indices. We benchmarked the approach against baseline load-balancing methods, varying both the number of files to be distributed and the number of workers, and found that it reduces index color table size by up to 8% and stored k-mer count by up to 15% over baseline. See the [project page](/portfolio/genomic-load-balancing/) for more detail.
